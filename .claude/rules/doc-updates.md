# Doc Update Log Rules

ドキュメント更新履歴（`/docs/doc-updates`、トップページ、サイドバーのバッジ）のデータは `src/data/docUpdates.ts` にある。

## いつ書くか

- `docs/` のページを追加したとき、または読者に知らせる価値のある更新をしたときに、同じブランチでエントリを追加する。
- 誤字、相互リンクの追加、表記ゆれの修正だけなら書かない。
- 日付は `main` にマージして公開される日にする。マージが遅れたら日付を直す。

## 粒度

- 1エントリ = 1テーマ（PR 1本、または同じ目的の一連の変更）。コミットごとに分けない。
- 新しいカテゴリを作ったときは、全ページを並べず、カテゴリの入口ページ1件にまとめて note にページ数を書く。
- `items` には読者が開く理由のあるページだけを入れる。リファレンスにガイドへのリンクを足しただけのページは入れない。
- `note` には、そのページで何が増えたかを短く書く（例: `突風（Gust）の展示動画`）。
- 見出しへの `hash` は、明示ID（`{#id}`）のある見出しだけに使う。

## サイドバーのバッジ

- 追加から30日は `NEW`、更新から14日は点を表示する。判定はビルド時の日付で、`deploy.yml` の週次実行で期限切れを消す。
- 大量のページを機械的に直した更新など、目立たせる必要がない項目には `badge: false` を付ける。

## 英語

- エントリの本文は日本語で書く。英語は日本語が確定してから対応する。
